## Overview

**MOverlay - Master Page Tool [KZY]** is a lightweight, efficient desktop utility designed to eliminate performance bottlenecks in Variable Data Printing (VDP). 
It solves the challenge of combining a static "master" PDF background (containing heavy graphics) with a dynamic "variable" PDF containing changing elements—such as 
sequential numbering, names, or codes—across hundreds of pages without straining system resources.

---

## Core Problem Solving

Working with hundreds of pages of heavy graphics for personalized print runs often introduces severe workflow friction:
* **System Lag & Unresponsiveness:** Standard design and heavy editing suites consume massive system memory, frequently causing low-end computers to freeze or crash when rendering hundreds of graphic-heavy pages simultaneously.
* **Storage Inefficiency:** Maintaining hundreds of individual files that share the exact same background design wastes storage and makes global design edits nearly impossible.
* **Lack of Native Support:** Most printer drivers and graphic design suites do not feature dedicated master-page overlay capabilities for variable PDF layers.
* **Scarcity of Free Tools:** Reliable, stable, and free software dedicated purely to direct PDF-to-PDF master overlaying is rare.

### How MOverlay Solves It
MOverlay bypasses external spreadsheets or complex database setups. Instead, it takes **two direct PDF inputs**—your static master PDF and your variable PDF—and merges them into a single, cohesive, print-ready document with high performance and minimal memory overhead.

---

## Key Features

* **Direct PDF Overlay:** Seamlessly superimposes a variable PDF directly onto a master PDF template.
* **Lightweight Performance:** Optimized for low-end computers, ensuring smooth processing of heavy graphic files and large page counts without lag.
* **Storage Optimization:** Store a single master file and apply variable overlays on demand, eliminating redundant file duplication.
* **Universal Printer Compatibility:** Prepares single PDF file that print reliably on any standard printer software.
* **Zero Database Complexity:** Operates strictly on PDF inputs, keeping workflows fast and straightforward.

---

## Workflow

1. **Load Master PDF:** Select your static background/template PDF containing heavy graphics or structural layout.
2. **Load Variable PDF:** Select your dynamic variable PDF containing shifting text, numbers, or elements.
3. **Process & Overlay:** Execute the merge to generate a single, highly optimized output PDF ready for production.
